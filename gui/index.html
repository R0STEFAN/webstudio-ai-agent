Первинне налаштування Webstudio

Webstudio CLI та робочі залежності ще не встановлені. Натисніть кнопку нижче для автоматичного встановлення всіх необхідних пакетів, конфігурації та застосування системних патчів.

Процес може тривати 1-2 хвилини залежно від швидкості інтернет-з'єднання. Журнал встановлення транслюється в реальному часі нижче.

Прив'язка та синхронізація проєкту

Build ID використовується для синхронізації неопублікованих чернеток безпосередньо з конструктора Webstudio Builder.

Сесія та авторизація (Asset Bridge)

1. Відкрийте ваш проєкт у Webstudio Builder у браузері. 2. Відкрийте DevTools (F12) -> вкладка Network (Мережа). 3. Виконайте будь-яку дію (наприклад, клік або збереження). 4. Знайдіть будь-який запит до api/rest, перегляньте Headers: • Скопіюйте значення заголовка "Cookie". • Скопіюйте значення "x-csrf-token" або "csrfToken". 5. Вставте їх у поля вище та натисніть "Зберегти session.json".
